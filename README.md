# 貪食蛇 3D

學校期末專題：以 three.js 製作的 3D 貪食蛇網頁遊戲。不使用框架、不需要建置，瀏覽器直接執行。支援電腦與手機，介面有台灣正體中文與英文。

## 遊戲內容

### 三種世界

| 世界 | 地圖 | 移動方式 |
|---|---|---|
| 平面 | 20×20 平面，四種穿牆規則（全部可穿越、只能上下、只能左右、全部是牆） | 上下左右 |
| 坑洞 | 8×8 平面、深 5 層的立體空間 | 前後左右，加上升、下降 |
| 立方體 | 立方體的 6 個面，每面 10×10 | 相對轉向（左轉、右轉） |

- 簡單、普通、困難三種難度，三種世界都有障礙物，並保證地圖連通。
- **關卡代碼**包含世界與難度，例如 `BN-4F7K2Q`（B 坑洞、N 普通）。在主選單輸入同一組代碼，就能玩到一模一樣的關卡。
- 最高分依「世界 × 難度」共 9 種組合分開記錄。
- 切換分頁時自動暫停。

### 操作方式

| 世界 | 鍵盤 | 觸控 |
|---|---|---|
| 平面 | 方向鍵或 WASD | 在畫面上滑動 |
| 坑洞 | 方向鍵或 WASD 前後左右，Q 上升、E 下降；按住滑鼠右鍵拖曳可轉動視角 | 滑動前後左右，畫面下方按鈕上升、下降；雙指轉動視角 |
| 立方體 | ← → 或 A D 左轉、右轉 | 點畫面左半邊左轉、右半邊右轉 |

三種世界都以空白鍵、P 或 Esc 暫停，手機可按上方的暫停按鈕。

### 輔助設計

- **坑洞**：蛇身依層數上色；蛇頭與食物投影在底面與牆面；蛇頭所在的層發亮；螢幕閱讀器會朗讀目前層數。
- **立方體**：每個面的底色略有不同；跨面時提示進入哪一面；採相對轉向，換面後方向不會顛倒。

### 顯示設定

主選單的「顯示設定」可以調整，設定會存在 `localStorage`（無法使用時改存記憶體，遊戲照常運作）：

- **主題**：簡約（預設，跟著系統淺色／深色）、霓虹（Bloom 發光）、高對比
- **畫質**：高（陰影與 Bloom）、低（關閉陰影與特效、限制解析度）；首次開啟依裝置自動選擇
- **減少動態效果**：預設跟著系統設定；開啟後食物動畫與立方體鏡頭轉向直接到位

不支援 WebGL 2 的瀏覽器會顯示說明頁，不會載入 three.js。

## 本機執行

本專案使用 ES Modules，必須透過本機伺服器開啟，無法直接雙擊 `index.html`。

```bash
# 使用 Python
python3 -m http.server 8000
```

再用瀏覽器開啟 `http://localhost:8000`。需要支援 WebGL 2 的瀏覽器（最新版的 Chrome、Edge、Firefox、Safari）。

## 部署

純靜態檔案，沒有建置步驟。在 GitHub 儲存庫的 Settings → Pages 選擇要發布的分支與根目錄 `/`，即可用 GitHub Pages 發布。

## 專案結構

```
index.html
css/style.css          介面樣式與各主題的介面配色
vendor/three/          three.js 與附加模組、授權
docs/PLAN.md           技術棧與實作計畫
js/
├── main.js            進入點與遊戲流程
├── config.js          難度、地圖大小、畫質等可調整的數值
├── game.js            遊戲狀態機
├── level.js           關卡生成與關卡代碼
├── random.js          種子亂數
├── storage.js         設定與最高分
├── i18n.js            多國語言（locales/ 為語言檔）
├── input.js           鍵盤與觸控
├── ui.js              選單、分數列、各種畫面
├── worlds/            平面、坑洞、立方體三種世界
├── render/            渲染器、地圖、蛇與食物、鏡頭、坑洞輔助、畫質
└── themes/            3D 主題配色
```

遊戲規則與關卡生成（`game.js`、`level.js`、`worlds/`）不存取 DOM 或 three.js，只透過世界介面（`cells`、`move`、`toPosition`）處理格子資料；繪圖都集中在 `render/`。
