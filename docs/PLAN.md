# 貪食蛇 3D：技術棧與實作計畫

> 學校期末專題，預計 2026 年 12 月底前完成。

## 一、專案定位

- 以 three.js 製作的 3D 貪食蛇網頁遊戲，是獨立的一款遊戲，沒有 2D 模式。
- 多國語言、儲存、種子亂數等模組沿用期中專題的寫法，依 3D 的需求修改。

## 二、遊戲內容

### 2.1 三種世界

| 世界 | 地圖 | 移動方式 | 鏡頭 |
|---|---|---|---|
| 平面 | 20×20 平面，四種穿牆規則 | 上下左右 | 固定斜上方視角 |
| 坑洞 | 8×8 平面、深 5 層的立體空間，四周與底部是牆 | 前後左右，加上升、下降 | 從坑口往下看，可小幅度旋轉 |
| 立方體 | 立方體的 6 個面，每面 10×10 | 相對轉向（左轉、右轉） | 跟在蛇後上方，跨面時平順旋轉 |

### 2.2 共通規則

- 簡單、普通、困難三種難度，三種世界都有障礙物，並保證地圖連通。
- 關卡代碼包含世界類型與難度，例如 `BN-4F7K2Q`（B 坑洞、N 普通）。
- 最高分依「世界 × 難度」共 9 種組合分開記錄。
- 台灣正體中文與英文、暫停、開局提示、切換分頁時自動暫停。

### 2.3 輔助設計

- **坑洞**：蛇身依層數上色；蛇頭與食物投影在底面與牆面；蛇頭所在的層發亮；螢幕閱讀器朗讀目前層數。
- **立方體**：每個面的底色略有不同；跨面時提示進入哪一面；採相對轉向，避免換面後方向顛倒。

## 三、技術棧

| 項目 | 決定 |
|---|---|
| 3D 函式庫 | three.js r186，使用 WebGLRenderer |
| 載入方式 | import map，檔案放在 `vendor/three/`，附 MIT 授權 |
| 附加模組 | 後製特效：EffectComposer、RenderPass、UnrealBloomPass、OutputPass（F5 加入） |
| 語言 | 原生 JavaScript（ES Modules），不使用框架與建置工具 |
| 介面 | HTML／CSS 疊在 3D 畫面上 |
| 儲存 | `localStorage`，前綴 `snake3d:`，與期中專題分開 |
| 部署 | GitHub Pages |

不支援 WebGL 2 的瀏覽器顯示說明頁，不載入 three.js。

### 程式碼規範

- 註解、文件、commit 訊息、介面預設文字一律使用台灣正體中文。
- 變數、函式、檔案名稱使用英文。
- 縮排 2 格，使用 UTF-8 編碼。

## 四、架構

### 4.1 世界介面

三種世界提供相同的介面，遊戲規則與關卡生成只透過這些功能運作：

- `cells()`：列出所有格子
- `move(cell, direction)`：回傳走一步後到達的格子與新方向；撞牆時回傳 `null`
- `toPosition(cell)`：回傳格子在 3D 空間中的座標與朝向，供繪圖使用

### 4.2 專案結構

```
index.html
css/style.css
vendor/three/            three.js 與特效模組、授權
docs/PLAN.md             本文件
js/
├── main.js              進入點與遊戲流程
├── config.js            難度、地圖大小、機率等數值
├── game.js              遊戲狀態機（透過世界介面運作）
├── level.js             關卡生成與關卡代碼
├── random.js            種子亂數
├── storage.js           設定與最高分
├── i18n.js              多國語言
├── locales/             中英文語言檔
├── input.js             鍵盤與觸控（滑動、點擊、畫面按鈕）
├── ui.js                選單、分數列、各種畫面
├── worlds/
│   ├── flat.js          平面世界
│   ├── pit.js           坑洞世界
│   └── cube.js          立方體世界
├── render/
│   ├── scene.js         渲染器、燈光、畫質設定、後製特效
│   ├── actors.js        蛇、食物、障礙物（InstancedMesh、平滑移動）
│   ├── cameras.js       三種世界的鏡頭
│   └── guides.js        坑洞投影輔助、立方體面提示
└── themes/              3D 主題
```

### 4.3 主題與畫質

- **主題**：簡約扁平（預設，跟著系統淺色／深色）、霓虹（Bloom 發光）、高對比無障礙。
- **畫質**：高（陰影與 Bloom）、低（關閉陰影與特效、限制解析度），首次開啟依裝置自動選擇。

## 五、操作方式

| 世界 | 鍵盤 | 觸控 |
|---|---|---|
| 平面 | 方向鍵或 WASD | 滑動 |
| 坑洞 | 方向鍵或 WASD 前後左右，Q 上升、E 下降 | 滑動前後左右，畫面按鈕上升、下降 |
| 立方體 | ← → 或 A D 左轉、右轉 | 點畫面左半邊左轉、右半邊右轉 |

三種世界都以空白鍵、P 或 Esc 暫停。

## 六、風險與對策

| 項目 | 對策 |
|---|---|
| 坑洞的深度判斷 | 層數配色、投影、目前層發亮，試玩後調整 |
| 立方體的跨面方向轉換 | 實際試玩驗證所有「面 × 方向」的轉換 |
| 立方體的鏡頭 | 四元數平滑旋轉；開啟「減少動態效果」時直接切換 |
| 手機上的 Bloom 效能 | 畫質設定依裝置自動選擇 |
